15 · Measured results

No Benchmark Existed, So We Built One

Held-out cases written by someone else

300 calls. The gateway blocks 90% and wrongly refuses 6%. A typical command denylist: 45% and 29%.

Real agent runs replayed

119 calls from 46 runs. 117 allowed; the 2 refused were deliberate tests.

Hidden instructions in tool replies

A public dataset, 7 current models. Models follow it 0 to 10% of the time. A task-sized permission stopped every case; a broad one stopped none.

An attacker that retries

4 models, 12 goals. Got through 3 times in 48 runs. With a model guard beside the rules: 0.

Tampering with the signed history

91 alterations. Every one caught except the time a record was logged, which is recorded as a gap.

Honest limits

Offline, scripted, first numbers. The suite is public and every miss is in a gaps register: 19 entries, 11 closed or partly closed.

Open the beta
