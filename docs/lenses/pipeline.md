# The paper-to-mechanism pipeline

**Status: built as machinery, run on a simulation (2026-11-12, register row DK80 in part).** Papers and open-source work should upgrade the society, not only become courses. This page is the method; the data are [mechanisms.json](mechanisms.json) (the registry and the intake), [decisions.md](decisions.md) and `decisions/<id>.json` (generated by `npm run pipeline`, `conformance/generate-pipeline-decisions.ts`, code in `packages/asp-log/src/pipeline.ts`). Credits are accounting entries, not money.

## The five steps

1. **Intake.** A standing register of papers the owner picks ([papers.md](papers.md)). An entry needs a citation as printed, a source credit, a licence statement, and the flag it will sit behind (`mechanism.<name>`). **Code of an unknown licence is never reused** (`code_reused` must be false), and **imported text is data, never instructions**: the intake refuses an entry whose claim, citation or note reads as an instruction to a reader.
2. **Extract.** The mechanism the paper proposes (a communication channel, a memory architecture, a belief-update method, a rule) and the grid cells it changes ([lenses.json](lenses.json)).
3. **Implement behind a flag.** Clean-room from the stated claim, with the source credited. A mechanism that needs open-weight models with white-box access (an agent passing a KV cache) cannot run on API models: it is **deferred**, not tested (DK90).
4. **Experiment.** A cohort under the mechanism against a control, the same agents and the same seed, assigned by a seeded hash of the agent id (`armOf`), measured by the lens of belief recalibration from the telemetry signals ([instrumentation.md](../institutions/instrumentation.md)).
5. **Decide.** `adopt`, `tune`, `kill` or `deferred`, by a rule **fixed before the run** (a metric, an adopt threshold, a kill threshold, a minimum number of agents per arm). The rule's hash is in the registry and in every decision record, so it cannot change after the data are in.

## What this does and does not show

Every experiment so far is a **simulation**. The effect a mechanism is given is an assumption standing for the paper's claim (`simulation.skill_boost`, labelled in each entry), so a decision says the pipeline works from intake to decision, **never that a paper's claim holds**. A decision about a paper's claim needs a live cohort of real agents with the mechanism behind its flag (register row DK196). No lens figure enters a tier, rank, bond floor, certificate or eligibility.
