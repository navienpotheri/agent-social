## Reflexion (Shinn et al., arXiv 2303.11366, v4 2023; CC BY 4.0; code github.com/noahshinn024/reflexion)
**Claim:** agents improve across trials without weight updates by turning feedback into verbal self-reflections in an episodic memory. **Method:** (1) an Actor produces a trajectory; (2) an Evaluator scores it (exact match, a heuristic, an LLM judgement, or self-written unit tests); (3) a self-reflection model writes a first-person lesson naming the faulty step; (4) append it to memory, capped at a sliding window of 1 to 3 entries; (5) the next trial conditions on the reflections; repeat until pass or a trial limit; (6) code variant: LLM-generated tests kept only if they parse, up to 6. **Results:** ALFWorld 130 of 134 solved (ReAct alone plateaus, 22% hallucination); HumanEval Python pass@1 91.0 (prior 80.1), Rust 68.0 (60.0); MBPP Python 77.1 (below SOTA 80.1); LeetcodeHard 15.0 (7.5). **Ablation (HumanEval Rust, 50 hardest, GPT-4):** base 0.60; no tests 0.52; no reflection 0.60; full 0.68; with a weak model (starchat-beta) no gain: reflection needs a capable model. **Limits:** can stall in local minima; bounded memory; fails for non-deterministic or API-calling code; no guarantee; relies on the model's self-evaluation. **Practice tasks:** (1) a 3-trial loop with a binary checker and a one-sentence reflection that names the faulty step; (2) a four-arm ablation on 20 small coding tasks, reporting raw counts and that n is too small for significance; (3) a memory-cap experiment (1, 3, unbounded).

## ACE: Agentic Context Engineering (Zhang et al., arXiv 2510.04618, v3 2026; CC BY 4.0; code github.com/ace-agent/ace)
**Claim:** treating context as an itemised, incrementally updated playbook avoids brevity bias and context collapse. (Not strictly append-only: new bullets appended, existing ones updated in place, a dedup step prunes.) **Method:** each bullet has an id, helpful and harmful counters and content; a Generator runs the task and marks bullets that helped or misled; a Reflector extracts lessons from the trace and feedback (up to 5 refinement rounds); a Curator writes a small delta (new bullets and counter updates), never a rewrite; the merge is deterministic and not an LLM; dedup by embedding similarity; offline epochs or online predict-then-update. **Results:** AppWorld offline with ground truth 42.4 to 59.4 (+17.0), without ground truth 57.2; finance 69.1 to 81.9 offline; cost against GEPA: latency 9,517 s vs 53,898 s, rollouts 357 vs 1,434. **Ablation (AppWorld):** full 59.4; no Reflector and no multi-epoch 55.1; no multi-epoch 56.8. **Limits:** needs a reasonably strong Reflector; without reliable feedback it can degrade (finance online without ground truth fell to 65.4, below base 69.1); some tasks need little context. **Practice tasks:** (1) write one delta and show the deterministic merge (new id plus a counter); (2) show context collapse: a rewrite that keeps 3 of 10 bullets against a delta that keeps all 10 and adds 1; (3) test feedback dependence with and without ground truth.

## SOTOPIA (Zhou et al., arXiv 2310.11667, v2 2024; CC BY-SA 4.0; sotopia.world)
**Claim:** an open-ended role-play environment scored on seven dimensions evaluates social intelligence, and GPT-4 can stand in for humans on some (Goal, Financial, Relationship). **Method:** a task = scenario, two characters (personality, values, secrets) and a private goal each; the relationship sets what each sees (close: all but secrets; acquaintance: public info; stranger: nothing); round-robin, at most 20 turns; each turn the agent chooses speak, non-verbal, physical, none or leave; an evaluator scores Goal 0 to 10, Believability 0 to 10, Knowledge 0 to 10, Secret -10 to 0, Relationship -5 to 5, Social rules -10 to 0, Financial -5 to 5. **Results:** GPT-4 Goal 7.62, GPT-3.5 6.45, Llama-2-70B 5.38, MPT-30B 4.10; GPT-4 vs human Pearson: Goal 0.71/0.78, Financial 0.62/0.34, Relationship 0.56/0.49; Secret 0.22; human agreement kappa 0.503; on the 20 hardest tasks humans out-scored GPT-4. **Limits:** the evaluator is biased and poor on Secret, Knowledge, Social rules; dyadic only; agents leak secrets and drop personas. **Practice tasks:** design an episode with a secret and a goal; a visibility drill for each relationship; audit a transcript where the goal is met but a secret leaks.

## AutoManual (Chen et al., arXiv 2405.16247, v4 2024; CC BY 4.0; code github.com/minghchen/automanual)
**Claim:** a Planner that acts by code plus a Builder that keeps a typed, example-grounded rule set, compiled by a Formulator into a manual, lets one human example reach high success and avoids replaying old paths. **Method:** seed with one example and a few rules, cap at 12 rules; the Planner cycles Analysis, Related Rules (by id), Overall Plan, Code; outcomes Direct Success, Indirect Success or Failure feed a skill library (successes) and a reflection library (failures); the Builder first classifies the error as 'Imperfect Rules' or 'Imperfect Agent' (case-conditioned prompting) then calls write_rule, update_rule or stop; each rule has Type (six: Special Phenomenon, Special Mechanism, Useful Helper Method, Success Process, Corrected Error, Unsolved Error), Content, Example and Validation Logs; a Consolidator merges when over the cap; the Formulator emits a Markdown manual. **Results (success %, GPT-3.5 / GPT-4-turbo):** ALFWorld ReAct 41.9/76.8, Reflexion 59.8/85.9, AutoManual 86.2/97.4 with one example; MiniWoB++ all types 92.7/98.3; WebArena Reddit 65.1. **Ablation (ALFWorld, GPT-4):** no online/libraries 77.6; libraries only 88.1; full 97.4; without Type 91.5, without Example 92.7, without Planner-Builder cooperation 93.8. **Limits:** needs a strong model; all rules in context (does not scale without retrieval); the Builder is overconfident. **Practice tasks:** turn a failed trace into one rule per type; classify a failure as imperfect rules or agent; consolidate 14 rules to 12 keeping both examples.

## EconAgent (Li et al., arXiv 2310.10436, v4 2024; CC BY 4.0; code github.com/tsinghua-fib-lab/ACL24-EconAgent)
**Claim:** LLM household agents with perception, memory (quarterly reflection) and action produce more plausible macro patterns than rule-based and RL baselines. **Method:** monthly step, 100 agents; each decides work willingness and a consumption share in [0,1] from a first-person prompt (profile, last month's job offer, current prices, rate); wage and price move by capped random fractions (0.05, 0.10) toward the imbalance; progressive income tax redistributed; a Taylor-rule rate each January (natural 1%, target 2%, unemployment 4%); keep the last 3 conversations and reflect each quarter. **Results:** inflation within -5% to 5% after year 3 (baselines above 20%); Phillips r = -0.619, Okun r = -0.918. **Ablations:** no perception gives overly stable inflation and unemployment; no reflection gives inflation anomalies near 15% in years 1 to 3. **Limits:** households only (no firms, no Beveridge curve); one model (GPT-3.5); about $30 and 2 hours per run; hyperparameters tuned for plausibility. **Practice tasks:** compute a Phillips correlation from five (unemployment, wage inflation) pairs; write one agent's monthly loop with given numbers; design a no-reflection ablation.

## Just Ask for Calibration (Tian et al., arXiv 2305.14975, v2 2023; CC BY 4.0)
**Claim:** for RLHF models, verbalised confidence is often better calibrated than token probabilities, and asking for several guesses first improves it (relative ECE cut often about 50%). **Method:** compare label probability (share of 10 samples), is-True probability, verbalised 1-stage top-k, 2-stage top-k, 2-stage chain-of-thought, and linguistic phrases mapped to numbers; score with ECE, temperature-scaled Brier and AUC of selective accuracy. **Results (ECE, label prob. to best verbalised):** gpt-3.5 TriviaQA 0.140 to 0.050; SciQ 0.256 to 0.065; TruthfulQA 0.451 to 0.125; gpt-4 TriviaQA 0.078 to 0.025; Llama-2-70B gains mixed. **Analyses:** top-2 or top-4 usually beat top-1; 1S and 2S can differ a lot; chain-of-thought did not help; numbers as good as words. **Limits:** short factual QA only; correctness judged by an LLM; ECE can be perfect for a constant 50%, hence the extra metrics. **Practice tasks:** compute ECE for ten given confidences and outcomes (five bins; the model answer gives 0.15 with absolute gaps); design a 1S against 2S comparison; build a phrase-to-number map from a calibration set.

## Chain-of-Verification (Dhuliawala et al., arXiv 2309.11495, v2 2023; arXiv non-exclusive licence)
**Claim:** draft, plan verification questions, answer them without the draft in view, then revise: fewer hallucinations. **Method:** baseline answer; plan questions; execute in one of four ways (joint, 2-step, factored with each question in its own prompt, factor-and-revise with a cross-check); final revised answer. **Results (Llama 65B):** Wikidata list precision 0.17 to 0.36 (2-step); Wiki-Category 0.12 to 0.22; MultiSpanQA F1 0.39 to 0.48; biographies FactScore 55.9 to 71.4 (factor+revise), above ChatGPT 58.7 and PerplexityAI 61.6. **Analyses:** a verifier that sees the draft repeats its errors; open questions beat yes/no (0.22 vs 0.19); a length control moved FactScore only 41.3 to 42.7. **Limits:** does not eliminate hallucination; factual errors only; many more prompts; small benchmarks (56, 55, 418); yes/no framing invites agreement. **Practice tasks:** run factored CoVe on a six-item list (4 of 6 verified: precision 0.67 to 1.0); test the repetition claim by planting a wrong fact; rewrite yes/no verification questions as open ones.

## Mem0 (Chhikara et al., arXiv 2504.19413, v1 2025; arXiv non-exclusive licence; mem0.ai/research)
**Claim:** extracting, consolidating and retrieving compact memories beats RAG and other memory systems on LOCOMO's LLM-judge score at far lower latency and tokens than full context. **Method:** per message pair, an LLM extracts candidate facts from the summary, the last 10 messages and the new pair; for each, retrieve the 10 most similar memories and let the LLM choose ADD, UPDATE (only if the new fact has more information), DELETE (it contradicts) or NOOP through a tool call; at answer time retrieve both speakers' memories, prefer the most recent, convert relative dates; Mem0g adds a graph of entities and relations with invalid-marking instead of deleting. **Results (J score):** Mem0 66.88, Mem0g 68.44, full context 72.90 (about 26,000 tokens), best RAG 60.97, Zep 65.99, OpenAI memory 52.90; p95 latency 1.44 s vs 17.1 s for full context; 1,764 memory tokens vs 26,031. **Limits:** one benchmark (adversarial category excluded); LLM judge is generous; no formal ablation; timestamps can be dropped; graph adds latency and no multi-hop gain. **Practice tasks:** apply ADD/UPDATE/DELETE/NOOP to four candidate facts; show that a token F1 of 0.86 can be a wrong answer; pick the system that fits a stated latency and token budget.

## JudgeAgent (Shi et al., arXiv 2509.02097, v4 2026; arXiv non-exclusive licence; code github.com/DataArcTech/JudgeAgent)
**Claim:** a context-graph-driven, difficulty-adaptive, multi-turn interview exposes knowledge gaps better than static tests, and feeding its report back raises accuracy on the seed questions. **Method:** batches of 3 seed questions; gains 1, 1.5, 2 for Easy, Medium, Hard; running average sets the next difficulty (Easy at most 0.5, Medium at most 1, Hard above); an offline entity graph of the knowledge base; up to 3 rounds of hop-based question extension; a written feedback report that does not give the answer; validation by re-asking the seed with the report injected (ACC1, ACC2, correction rate, correct-to-error rate). **Results (GPT-4.1 core):** MedQA ACC 84.97 to 92.44 (GPT-4.1 target); MultiHopRAG 68.94 to 75.55; per-round gain falls 2.04, 1.13, 0.71, 0.23 percent (hence the cap of 3); fine-tuning on the benchmark raised the static score by 20.34 but changed the first extended round by -4.35 (contamination reading). **Limits:** the generator and a target are the same model (a possible confound); round 3 drifts; the metric measures whether feedback helps, not whether the diagnosis is right. **Practice tasks:** compute the next difficulty from given outcomes; read the contamination table; design a different-generator test.
