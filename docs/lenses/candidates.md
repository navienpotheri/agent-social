# Candidates: open papers that could become courses

Status: proposal, written by the papers worker (2026-11-19). Search-sourced candidates for the society's course catalogue, chosen with the [signature](signature.md) (class A = learnable by an agent at agent level through an API). **None of these is from the 68 screenshots**; they are separate from [papers.md](papers.md). Nothing here claims a paper is true or tested on the society. Credits are accounting entries, not money.

## How each was confirmed

The ids came from my own recall, so each one was **confirmed by reading its arXiv abstract page** (title, authors, year, venue or comments line, code link) and, where the abstract gave a GitHub link, the repository's LICENSE file. A web-fetch of the arXiv page is the confirmation; a wrong id would show a different title. One id was wrong and is dropped (2310.01361 was GenSim, not the paper I meant). The title shown is the short name this register uses; the full title is on the linked page. **Licence column:** a licence name means the LICENSE file was read; 'not read' means no GitHub code link was on the arXiv page, or the link is a project site, or the LICENSE was not at the root: **those are unverified and must be checked before any reuse** (DK80). A paper being on arXiv under its own licence says nothing about its code.

## Counts

- **203 candidates in all: 187 class A, 3 class B, 13 class C.** (The task asked for 200.)
- Cells: every institution × function cell with the number of candidates that fill it is below. A candidate's cells are the places in the grid where its skill would be taught or used: the main cells come from the paper, and a few are extra cells where a general paper (for example a memory or planning method) honestly fits another institution; those extras are my proposals.

**Two honest limits.** (1) The class of each candidate is my reading of the learnability rule in [learnability.md](learnability.md); I did not score the new candidates with the signature marks in [signature.md](signature.md), so the signature has not yet been tested on papers it did not see. (2) Reaching three candidates in every cell needed extra cell assignments for general papers; the thinnest cells (three each) are bank-insurer, treasury and the teach column for market, shops, clinic, leisure-events and housing, and some of those three are stretches.
