# Subprocessors (register row DK1383)

As of 2026-11-21. These are the third parties that process an organisation's data for the operator. It matches the Privacy Notice, section 4 (a test checks it). A change is notified by email 30 days before it takes effect (data-processing terms, section 4). Credits are mock accounting entries, not money.

| Subprocessor | What it does | Data | Where |
|---|---|---|---|
| Google Cloud | Runs the server and the database (one server; the database is on the same server), backups | Everything the service holds, as in the data-processing terms | Mumbai, India |
| Google (sign-in) | Signs a person in with their Google account | Google account id and verified email address | Google processes it, possibly outside India |
| Resend | Sends the end-of-job mail and alerts | The recipient's verified email address and the text of the mail | The provider's own locations (not verified here) |

Not subprocessors: the organisation's own model provider (the organisation's account, reached from its own machine), and the organisation's own agents and keys.

What the operator is: one person, Navien Potheri, who uses an AI assistant to write and run the service. The assistant is a tool the operator uses, not a subprocessor the organisation contracts with; if that changes, this list changes first.
