# Learning pilot: the decision rule, written before the run

Written 2026-10-19 (SHA-256 of the first version: ef0fea2815fcc53b895f11a8e5b555a287836efecd6fbba909cac56783022136), before any pilot-v2 session was run and before the calibration reading was seen. It is not to be changed after results, in either direction: not the tasks, the margins, the number of rounds or the way the floor is computed. If a run turns out to be invalid for a reason named below, it is discarded and re-run under the same rule, never re-judged.

**The claim being tested.** An agent that carries what it learned from rejections (a Learner) does measurably better on tasks it has not practised than the same agent without that memory (a Static agent), and the bond floor computed from its record is lower for it. This is the thesis behind docs/credits-and-learning-experiment.md; pilot v1 was inconclusive (a provider limit was counted as failure; the tasks were too easy).

**Amendment 1, 2026-10-19, made before any pilot-v2 result existed.** The model is changed from the free `nvidia/nemotron-3-super-120b-a12b:free` to the paid **`openai/gpt-4o-mini`** on OpenRouter ($0.15 a million input tokens, $0.60 output; tool calls supported), with a hard spending cap of **$2** (`--max-spend 2`, counted from the run logs; the run stops before the next session at the cap). Reason: on the free tier two calibration attempts today were spoiled by provider errors (three sessions ended in HTTP 500 and were scored as failures, then a 429 on the key; the second attempt had 4 sessions, 0 passed, three timeouts), so the free tier cannot give a run with no gaps. Nothing else in this rule changes: the tasks, the thresholds and the way the floor is computed are as first written. Both calibration attempts on the free model are discarded (kept as `learning-calibration-1-invalid` and `learning-calibration-2-free-stopped`), and the calibration is taken again on the new model before the pilot. One model is used for every session, including the calibration and both agents, so the two agents are compared on the same model.

**Amendment 2, 2026-10-19, also before any pilot-v2 result.** (a) The calibration on the paid model found every file an agent wrote with PowerShell saved as UTF-16 with a byte-order mark: the code was correct and Node could not read it (`SyntaxError`), which would have made every agent fail for reasons unrelated to skill. The check now reads the agent's source as what it is and saves it as UTF-8 before checking, for every agent alike (`normalizeEncoding` in evals/learning/tasks.mjs, with a self-test); nothing about the tasks, the house rules or the thresholds changes. **Amendment 3, 2026-10-19, before any pilot-v2 result.** The calibration on `openai/gpt-4o-mini` (10 held-out tasks, no notes, folder `learning-calibration-v3`) was **valid**: the tests passed on 9 of 10 tasks and the full check, with the hidden house rule, on 0 of 10; its 10 sessions cost about $0.18, so about $0.018 a session. At that rate the planned 130 sessions cost about $2.35, above the $2 cap in Amendment 1, so the owner raised the cap to **$3** (`--max-spend 3`) rather than shrink the design. Everything else is unchanged: 6 rounds of 10 held-out tasks, the same tasks, thresholds and floor.

**What is run.** `node evals/learning/pilot.mjs --rounds R --n N --model openai/gpt-4o-mini --max-spend 3` on the 40-task set (evals/learning/tasks.mjs, commit 6386cb8, with the later runner fixes: provider errors are retried and then stop the run, and a spending cap), Codex through `asp run codex --local`, agents interleaved, one practice job a round, a reading of N rotating held-out tasks each round (round 0 is the baseline). Defaults for this pilot: R = 6, N = 10 (about 130 sessions, a little over a day of the free tier); the state file lets it resume.

**A run is valid only if all of these hold; otherwise it is discarded and repeated, and its numbers are not used:**
1. No session was refused by the provider (the runner stops and counts nothing if one is).
2. The calibration reading (10 held-out tasks, no notes) is valid when the **tests pass on at least 30%** of the tasks (the model can do the underlying tasks at all) and the **full check, which includes the hidden house rule, passes on at most 70%** (there is something left to learn). A full pass rate near zero is expected and valid, because the house rules are hidden: improvement shows as a rise from near zero. (This replaces the first wording, "between 5% and 70%", which contradicted the next sentence; see Amendment 2.)
3. Every planned session completed (no reading is missing).

**The decision, by the last round R, from the held-out readings (N tasks each):**
- **Gap found** if the Learner's pass rate is at least **0.30 higher** than the Static agent's, **and** the Learner's floor from `bondFloorPermille` (the smoothed estimate, step 0.15, baseline of 2 readings, as in evals/bond-floor-sim.mjs and `track` in pilot.mjs) is at least **100 permille lower** than the Static agent's, **and** the Static agent's pass rate at round R is no more than 0.15 above its own baseline (it did not improve by itself).
- **No gap** if the Learner's pass rate is less than **0.10 higher** than the Static agent's at round R.
- **Inconclusive** in every other case (a gap between 0.10 and 0.30, or a gap in pass rate without the 100 permille in the floor). Inconclusive is a design failure to be fixed before anything is reported as a result: more tasks a reading, more rounds, a repeat.

**Reported whatever comes out,** including "no gap". One run is one run: a gap found in a single run is reported as one run, and the floor difference is read against the noise the simulation predicts (about 50 permille between identical agents at 20 tasks a reading, more at 10).

**Not done here, on purpose.** No third agent (the design doc names a Careless one, and the simulation an Overfitter) until the owner defines it; no paid model without the owner's say-so; the key is never printed or committed.

**Amendment 8, 2026-10-19, before the re-run (Stage A2), at the owner's instruction: every outcome of a valid run is a decision.** The owner objected that a result may not be left "inconclusive". Two things had been under that word, and they are separated. (1) An **invalid run** (Amendment 4's tool-reliability condition; Amendment 7's condition that the Learner's tests-pass share is not under 60% while the Static agent's is over 80%) is **not a result and is never reported as one**: the run is repeated. This replaces the wording "read as inconclusive" in Amendment 7. (2) The **middle band** no longer ends the run. The rule is now sequential, and is the function `decide` in evals/learning/decide.mjs, covered by tests (packages/asp-cli/test/learning-decide.test.ts):

- **After round 5** (`--rounds 5`), as before: **gap** if the Learner's pass rate at round 5 is at least 0.30 above the Static agent's, its floor (`bondFloorPermille`) is at least 100 permille lower, and the Static agent's pass rate is no more than 0.15 above its own baseline; **no gap** if the Learner is less than 0.10 above; otherwise the **middle band**.
- **The middle band continues the run to round 8** (`--extend-to 8`; the saved state resumes), with the cost of about three more rounds (about 54 sessions).
- **At round 8 the decision is binary:** the full-check passes of the Learner and of the Static agent pooled over rounds 3 to 8 are compared with a **one-sided Fisher exact test**: **gap** if p < 0.05 and the Learner's pooled pass rate is at least 0.10 above the Static agent's; otherwise **no measurable gap at this size**, stated with the size (sessions and passes). A run that is still in the middle band at round 8 is thus decided by this test, not left open.
- The thresholds at round 5 (0.30, 100 permille, 0.15, 0.10) and the validity conditions are those already pre-registered; the added elements are the extension, the pooled test and its two numbers (p < 0.05, 0.10).

**Disclosure.** This amendment was written after the owner and the analyst had seen **partial data** from discarded runs (the Stage A run stopped after about 71 sessions). Nothing in it depends on the size of any effect, only on when to stop and which standard test to apply, but the choice of a pooled test over rounds 3 to 8 and the margin of 0.10 were made after that data was seen, and a reader should weigh the result with that in mind. One run is one run.
