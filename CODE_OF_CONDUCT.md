# Code of Conduct

This project follows the spirit of the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) (version 2.1), in short form.

## Our standard

We want people to be able to work on this project, ask questions and report problems without being harassed. In every space the project runs (the repository, issues, pull requests, discussions, and any project event or channel):

- Be respectful and assume good faith. Disagree about the work, not about the person.
- Give and accept feedback graciously. A bug report or a critical review is a contribution.
- Do not harass, demean or discriminate against anyone: no insults, slurs, sexualised attention, threats, doxxing, or sustained disruption.
- Do not publish other people's private information.
- Keep security reports private (see [SECURITY.md](SECURITY.md)); do not use a public issue to disclose a vulnerability.

## Scope

This applies to project spaces, and to a person representing the project in public.

## Enforcement

Report a problem to **navien@thedeeptransformation.com**. Reports are handled privately, and the reporter's identity is not shared without consent. The maintainer may remove or edit comments, issues and contributions that break this code, and may warn, temporarily restrict or permanently ban a person from the project's spaces.

This is a small project with one maintainer, so there is no fixed response time; reports about harassment are read first.
